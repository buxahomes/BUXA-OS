# Certification Checklist

- [ ] Exact `runtime-foundation-v1.0.0` tag and commit verified.
- [ ] SDK and all schema versions supported.
- [ ] Manifest and all Capabilities strictly valid.
- [ ] Engine taxonomy and identity correlation pass.
- [ ] Runtime Objects, States, transitions, and Decisions resolve.
- [ ] Permissions and side effects do not escalate.
- [ ] Registry entry, lifecycle, certification, and defaults are valid.
- [ ] Every positive fixture passes.
- [ ] Every negative fixture fails for its expected category.
- [ ] Engine Result fixtures use `runtime_execution_evidence_v1` when an Engine package exists.
- [ ] Evidence hashes reproduce.
- [ ] Validation report contains no ERROR or FATAL.
- [ ] Documentation links, fences, whitespace, and diff checks pass.
- [ ] Foundation source is unchanged.
- [ ] Engine Layer Governance records acceptance.
