# Repository Classification

> Repository Classification of the Scout Strategic Intelligence System

Version: 1.0

Status: Approved

Authority: Scout Repository

---

# Overview

Repository Classification defines how organisational assets are categorised within the Business Operating System.

Its purpose is to establish a consistent classification framework that improves asset discoverability, governance, reuse and long-term organisational capability.

Classification describes the organisational purpose of an asset rather than its storage location.

---

# Purpose

Repository Classification exists to organise organisational assets according to their business function.

Its objectives are to:

- Establish consistent asset categories.
- Improve repository discoverability.
- Support asset governance.
- Enable asset reuse.
- Reduce duplication.
- Strengthen organisational capability.

A consistent classification system improves both organisational efficiency and long-term asset management.

---

# Classification Principles

Repository Classification follows these principles.

## Purpose Before Location

Assets should be classified according to organisational purpose rather than physical storage.

Classification should remain independent of repository technology.

---

## Function Before Format

Asset categories should reflect organisational function rather than file type.

A PDF, spreadsheet or Markdown document may belong to the same asset category.

---

## Simplicity Before Complexity

Classification should remain understandable and scalable.

Unnecessary complexity reduces repository usability.

---

## Consistency Before Convenience

The same classification principles should apply across every repository domain.

Consistency strengthens governance.

---

## Scalability Before Completeness

Classification should support future organisational growth without structural redesign.

---

## Reuse Before Duplication

Assets should belong to meaningful organisational categories that encourage discovery and reuse.

# Asset Classifications

Repository assets may be classified into the following categories.

## Strategic Assets

Assets supporting long-term organisational direction.

Examples include:

- Business strategies.
- Roadmaps.
- Governance frameworks.

---

## Governance Assets

Assets defining organisational rules and responsibilities.

Examples include:

- Standards.
- Policies.
- Constitutions.
- Governance documents.

---

## Operational Assets

Assets supporting day-to-day organisational execution.

Examples include:

- Standard operating procedures.
- Checklists.
- Workflows.
- Templates.

---

## Product Assets

Assets supporting products and product management.

Examples include:

- Product Passports.
- Product specifications.
- Technical documentation.
- Product imagery.

---

## Brand Assets

Assets supporting brand consistency.

Examples include:

- Brand Guidelines.
- Logos.
- Communication Standards.
- Visual identity resources.

---

## Training Assets

Assets supporting organisational learning.

Examples include:

- Training manuals.
- Learning resources.
- Workshops.
- Onboarding materials.

---

## AI Assets

Assets supporting AI systems.

Examples include:

- Prompt libraries.
- AI workflows.
- AI operating instructions.
- Evaluation templates.

---

## Research Assets

Assets supporting organisational research and intelligence.

Examples include:

- Research reports.
- Market analysis.
- Competitive intelligence.
- Reference materials.

---

## Historical Assets

Assets retained for governance, traceability or historical reference.

Archived assets remain organisational resources.

# Classification Characteristics

Effective classification should be:

- Consistent.
- Scalable.
- Discoverable.
- Reusable.
- Governed.
- Easy to understand.

Classification should improve organisational capability rather than increase administrative complexity.

---

# Classification Responsibilities

Repository Classification is responsible for:

- Defining repository asset categories.
- Supporting asset discoverability.
- Improving organisational consistency.
- Enabling repository governance.
- Supporting asset reuse.
- Strengthening Business Operating System capability.

Classification provides a common language for organisational assets.

---

# Success Criteria

Repository Classification succeeds when organisational assets are:

- Correctly classified.
- Easy to locate.
- Easy to understand.
- Easy to govern.
- Easy to reuse.
- Organised consistently.

Success is measured by repository usability and organisational effectiveness rather than the number of categories created.
